# Twitch to Kick Bridge

Shows a Kick profile button on Twitch channels when the streamer is also on Kick.



Steps:

1. Create a Kick App: https://kick.com/settings/developer
2. Copy Client ID/Client Secret
3. Open Extension, click on Settings
4. Paste Kick's Client ID and Secret then press save.
5. Create a Twitch App: https://dev.twitch.tv/console/apps
6. Category: Browser Extension
7. Copy Client ID, make public. No Secret Needed
8. In OAuth Redirect URLs, put `http://localhost` save.
9. Open Extension settings, under 'Twitch' paste your Client ID, underneath you'll find a special URL named OAuth Redirect URLs. Press 'Add' in Twitch Dev Console and press save.
10. Open Edge or Chrome, press 'Load Unpacked'
